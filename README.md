# 📿 Islamic Life OS

> An Islamic psychology app connecting Quran & Sunnah to real life —
> adhkar tracker, AI dua finder, psychological healing through Islam,
> and the Seerah of Prophet Muhammad ﷺ as a life model.

## Features
- 🧠 AI-powered dua search by topic (rizq, anxiety, healing...)
- 📿 Adhkar tracker — Morning / Evening / Sleep with streaks
- 🫀 Islamic Psychology Lab — connect your struggles to Quran
- 🕌 Seerah personality model — the Prophet ﷺ in modern situations
- 📊 Personal data dashboard — streaks, sessions, patterns
- 🌐 English + Arabic + French (i18n + RTL)

## Stack
Vite · React 18 · Zustand · TailwindCSS · Recharts · Claude AI API

## Setup
```bash
npm install
echo "VITE_ANTHROPIC_API_KEY=your_key" > .env
npm run dev
```
